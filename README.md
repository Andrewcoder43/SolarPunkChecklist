## Introduction

The SolarPunkChecklist is a project designed to help you engage with and track your involvement in SolarPunk principles and activities. It provides a checklist of 70 items related to SolarPunk, allowing you to mark your progress and see your overall completion rate.

## Features

- Interactive checklist with 70 SolarPunk-related activities.
- Real-time progress tracking.
- User-friendly interface.
- Accessible via a web browser.

## How It Works

You can access the SolarPunk checklist at [https://andrewcoder43.github.io/SolarPunkChecklist/](https://andrewcoder43.github.io/SolarPunkChecklist/). As you complete each SolarPunk-related activity, simply click the corresponding empty box to mark it as complete. The total progress of completed activities is displayed at the bottom of the page.

## Getting Started

### Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/Andrewcoder43/SolarPunkChecklist.git
    ```
2.  Navigate to the project directory:

    ```bash
    cd SolarPunkChecklist
    ```
3.  Install the dependencies:

    ```bash
    npm install
    ```

### Usage

1.  Start the application:

    ```bash
    npm start
    ```

    This command will start the development server and open the application in your default web browser.

2.  Open your web browser and navigate to the address provided (usually `http://localhost:3000`).

3.  Interact with the checklist by clicking the empty boxes as you complete each activity.
